# WA Directory Magazine — ChatGPT Page Prompts

**Format:** portrait magazine, **8 pages max** (A4 portrait, 2:3), a user manual for
**buyers and sellers** only. Each page has its own standalone prompt — paste one prompt per
new ChatGPT chat (or one image generation each). Every prompt embeds the full design scheme
and the exact copy, so pages stay identical in style and no text is invented or garbled.

---

## The design scheme — "Chat & Check"

| Element | Spec |
|---|---|
| **Palette** | Paper `#FAF9F6` (warm off-white) · Ink `#0B141A` · WhatsApp green `#25D366` · Deep green `#075E54` · single accent sunshine gold `#F2A93B` |
| **Type** | Headlines: heavy condensed uppercase sans (Archivo Black / Anton), tight tracking, 40–60pt · Body: Inter regular 10–11pt, two-column grid · Labels/captions: IBM Plex Mono uppercase, letterspaced |
| **Illustration** | Flat vector only — rounded chat bubbles with tails, phone frames, QR-code squares, double green check marks, dotted route lines, simple storefront icons. No photos, no 3D, no gradients on people |
| **Furniture** | Small green square logo top-left with "WA DIRECTORY" · thin green hairline rules · large outlined page numeral in the bottom outer corner · footer `WA DIRECTORY · USER MANUAL · wadirectory.co.zw` |
| **Layout** | A4 portrait, 12-column grid, generous margins (≥15mm), one hero illustration per page max, whitespace-heavy editorial rhythm |

**Error guard (applies to every page):** render at **portrait A4 / 2:3 (1024×1536)**;
reproduce **every word exactly as written** — correct spelling, no lorem ipsum, no invented
words, no gibberish text, no watermark, no extra page numbers, no logos other than the ones
described; keep all text inside its zone (shrink type rather than truncate); palette and
typography must match the scheme above on all 8 pages.

## Usage notes

1. **One prompt per new chat** (or one image generation each) so the model has no stale
   context — each prompt is fully standalone by design.
2. **Assemble in order 1→8**; page numbers are baked into each prompt (2–8, cover unnumbered).
3. If a generation garbles a word, re-run only that page's prompt and add: *"Fix the text
   only — do not change layout, palette or illustration."*
4. For a print PDF later: regenerate at higher resolution with the same prompt plus
   *"same layout and exact text, render at 300 DPI A4 portrait (2480×3508)."*
